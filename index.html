Stooq CSV Adatforrás & Tesztelés

Amikor feltöltöd ezt az oldalt a GitHub repódba a bet_data.csv mellé, az alkalmazás automatikusan innen olvassa be az adatokat CORS hiba nélkül.

Ha már letöltötted a gépedre a bet_data.csv fájlt, itt azonnal betallózhatod, hogy még a GitHub-ra való feltöltés előtt kipróbáld az éles adatokkal:

GitHub Pages + Stooq CSV Telepítési Útmutató

Hogyan működik együtt a két fájl a GitHub-on?
  1. Kattints a felső sávban az „index.html Mentése” gombra, és töltsd fel a fájlt a GitHub repository-d gyökerébe index.html néven.
  2. A GitHub Actions munkafolyamat 15 percenként lekéri a Stooq-ról a 18 magyar részvényt + BUX indexet, és elmenti ugyanabba a mappába bet_data.csv néven.
  3. A GitHub Pages oldalad (https://neved.github.io/repo-neve/) közvetlenül beolvassa a ./bet_data.csv fájlt – nincs CORS hiba és nincs szükség proxyra!
GitHub Actions Workflow (.github/workflows/update_stooq.yml) 
name: Stooq BET Adatfrissites

on:
  schedule:
    # Hétfőtől péntekig, tőzsdei nyitvatartás alatt 15 percenként
    - cron: '*/15 8-16 * * 1-5'
  workflow_dispatch:

permissions:
  contents: write

jobs:
  fetch-data:
    runs-on: ubuntu-latest
    steps:
      - name: Repo letoltese
        uses: actions/checkout@v4

      - name: Stooq BET es Mid-Cap adatok lekerese
        run: |
          curl -s "https://stooq.com/q/l/?s=^bux+otp.hu+mol.hu+richt.hu+mtel.hu+opus.hu+4ig.hu+autowallis.hu+alteo.hu+waberers.hu+any.hu+masterplast.hu+pannergy.hu+graphisoft.hu+cigpannonia.hu+appeninn.hu+duna.hu+raba.hu+zwack.hu&f=sd2t2ohlcvn&h&e=csv" -o bet_data.csv

      - name: Adatok mentese a repoba
        run: |
          git config --local user.email "github-actions[bot]@users.noreply.github.com"
          git config --local user.name "github-actions[bot]"
          git add bet_data.csv
          git diff --staged --quiet || (git commit -m "Auto-update BET data" && git push)
